
# 💡 Topic

- **텍스트 인식 AI**를 이용한 일정 플래너
- 대한민국 공휴일 및 기념일을 확인할 수 있는 플래너
- `naverMap`을 이용해 약속 장소 저장
- 할 일,일정,기념일 등을 관리할 수 있는 여러가지 뷰 타입을 제공

# 📝 Summary

실제로 제가 필요하다고 느껴 제작한 앱입니다. 현존하는 플래너 앱은 많지만 꼭 한 가지씩 부족하다는 느낌을 받을 때가 많았습니다. 한가지 예시로 하나의 일정에 관련 정보나 텍스트를 메모에 옮겨 적는 저는 이런 반복된 작업이 귀찮을 때가 있었습니다. 이런 단순 반복된 작업을 없애고자 `google mlkit text recognition`을 활용해 텍스트를 촬영한 사진에 텍스트만 추출해 메모장에 바로 적용하는  기능을 갖춘 플래너 앱을 개발하게 되었습니다. 이러한 개선점을 시작으로 제가 필요한 기능들을 추가 하다 보니 주위에 반응이 좋아 상용 앱으로도 출시하였고 지속적인 유지보수와 업데이트를 진행하고 있습니다.

# ⭐️ Key Function

- **공공데이터(국내 기념일,공휴일)와 캘린더를 연동**해 캘린더에서 국내 기념일 공휴일 확인가능
- **카카오 주소검색 API**를 사용해 사용자가 검색한 위치 정보와 장소명을 불러옴
- 할 일, 일정, 기념일 등을 관리할 수 있는 여러 가지 뷰 타입을 제공
- 해당하는 일정에 위치를 저장할 수 있으며 저장한 위치를 지도 상 마커로 제공`NaverMap`
- 사용자가 지정한 시간에 **알람**을 제공
- **AI를 이용해 사진 속 텍스트를 일정 속 메모에 추가**
- **템플릿**을 만들어 일정에 추가 및 제거할 수 있음
- 내가 추가한 일정에 위치를 **전체 지도에서 마커**로 확인하고 수정 가능 → 해당 **마커** 선택 시 일정의 세부 정보 CRUD 가능
- 일정 추가 페이지에서 동일한 제목으로 작성할 경우 동일한 기존 데이터를 추천하고 붙여 넣기 가능
- **사용자 편의성**을 위해 분 단위로 `contextmenu` 를 제공하고 기존 시간에 선택한 시간을 쉽고 빠르게 추가 가능
- 여러가지 설정 기능을 제공해 사용자 취향에 따라 캘린더 꾸미기 가능 (캘린더 텍스트 크기,

        시작요일, 기념일 정보 켜기,다크 모드,서체 변경 등)

- **`In app purchase`**와 연동해 인앱 결제 구현
- `kakao adfit`을 연동해 광고 게재

# 💡 Learned

- 상태관리로 GetX를 도입해 [boilerplate code](https://en.m.wikipedia.org/wiki/Boilerplate_code)를 줄였으며 생산성을 높임.
- 알람을 요구사항에 맞게 구현하기 위해 여러 시행착오를 겪었으며 이를 통해  `flutter_local_notifications` 개념과 사용법 등을 알게 되었음.
- `isar Database`의 CRUD를 알게 되었음
- **`Camera`**를 통해 카메라 리소스의 사용법을 알게 되었음
- **`Shared_preferences`**를 활용해 getter , setter 개념을 익히고 사용법 등을 알게 되었음
- **`syncfusion_flutter_calendar`**와 `http` 를 활용해 **공공데이터(국가 기념일 및 공휴일)** 를 캘린더에 삽입하는 과정에서 공공 데이터에서 넘어오는 데이터를 변환하는 방법을 알게 되었음.
- `google mlkit text recognition` 와 `image_picker`를 활용해 갤러리 이미지를 불러와 이미지 속 텍스트를 인식해 캘린더에 텍스트를 삽입하는 경험을 함.
- `in_app_purchase` 구현부를 `getX`로 작성하는 경험을 가졌으며 스토어와 연동해 인앱 결제 기능을 구현하는 방법을 학습했음.
- `naver_map` 을 사용하며 마커 생성, 마커 이미지 변경, 카메라 전환을 배웠으며 DB에 저장되어있는 위치정보들을 지도에 마커로 보여주는 경험을 함.
- **kakaoApI**(주소검색)와 `naver_map`을 연동해 사용자가 주소 검색을 통해 얻은 주소를 맵에 마커로 적용하는 방법을 학습했음.
- `kakao_adfit` 을 활용 광고 게재 경험
